# Classroom 1 — терминал, GitHub workflow и первый Go-проект

Этот репозиторий используется на первом занятии для live coding.

## Цели урока

После урока ученик должен уметь:

1. Открывать терминал и понимать, куда вводить команды.
2. Перемещаться по папкам через `pwd`, `ls`, `cd`, `mkdir`, `touch`, `cat`.
3. Понимать базовый workflow GitHub: fork → clone → branch → commit → push → pull request.
4. Запускать первый Go-проект через `go run`.
5. Запускать тесты через `go test ./...`.
6. Понимать минимальную структуру Go-проекта: `go.mod`, `cmd`, `internal`, package, import.

## Как запустить проект

```bash
go run ./cmd/app
```

## Как запустить тесты

```bash
go test ./...
```

## Как запустить все проверки

```bash
make check
```

## План live coding

1. Открыть терминал.
2. Проверить текущую папку через `pwd`.
3. Посмотреть файлы через `ls`.
4. Открыть проект в VS Code.
5. Запустить `go run ./cmd/app`.
6. Изменить текст приветствия в `internal/greeter/greeter.go`.
7. Запустить тесты и увидеть ошибку.
8. Исправить тест или код.
9. Создать ветку, commit, push.
10. Открыть Pull Request.

## Мини-команды

```bash
pwd                 # показать текущую папку
ls                  # показать файлы
cd folder           # перейти в папку
cd ..               # выйти на уровень выше
mkdir projects      # создать папку
cat README.md       # показать содержимое файла
clear               # очистить терминал
```
