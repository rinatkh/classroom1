# Terminal cheatsheet

Терминал — это окно, куда мы пишем команды текстом.

## Навигация

```bash
pwd
ls
cd folder
cd ..
mkdir folder_name
touch file.go
cat file.go
clear
```

## Go

```bash
go version
go run ./cmd/app
go test ./...
go test -cover ./...
```

## Git

```bash
git status
git checkout -b lesson-01
git add .
git commit -m "complete lesson 01"
git push origin lesson-01
```
